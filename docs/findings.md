# Scientific findings

No accepted scientific findings are recorded yet. The current organism has not
been shown to implement an interpretable reasoning mechanism or support a
validated monitor of hidden computation.

This page accepts completed, controlled findings about the organism: training
comparisons, scoped same-checkpoint causal results, or monitoring evaluations.
Each finding must state its claim and limits, exact specimen and provenance,
controls, held-out evidence, uncertainty, and reproducible artifacts. A null
effect or a monitoring failure can be a finding; a capabilities gain is not a
condition of acceptance.

Exploratory observations belong in [journal.md](journal.md). Runtime parity,
throughput, and capture checks belong in
[runtime-qualification.md](runtime-qualification.md). Acceptance rules are in
[design.md](design.md) and [interpretability.md](interpretability.md).
