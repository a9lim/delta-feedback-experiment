# Figures for the model organism

No accepted-result figures are committed yet.

Figures should make a bounded result inspectable: an aligned state trajectory,
a paired intervention effect, a recurrent stability trace with behavioral
outcomes, or a monitor's calibration and error profile. A route heatmap alone
does not establish a mechanism, and a loss curve alone does not establish
reasoning or interpretability.

Promote a generated figure together with its accepted claim in
[findings](../docs/findings.md), exact checkpoint/data identity, generating
command, raw measurements, labels, and uncertainty. Distinguish observational
plots, causal interventions, and monitoring evaluations in the caption.
Exploratory outputs remain ignored; engineering figures belong with their
runtime records. Architecture diagrams, if committed, describe computation
rather than accepted behavioral findings.
